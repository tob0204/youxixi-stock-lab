# 油洗洗｜台股短期技術指標敏感度研究（v0.2）

**這是可部署在瀏覽器的輕量 Python + Streamlit 研究原型，不會下單。** 只在按「開始回測」時向 Yahoo Finance 非官方行情介面取得單檔台股歷史 OHLCV，沒有必備資料庫，使用 Streamlit 記憶體快取（1 小時）。

## 今晚最簡單的啟用方式：不需要安裝 Python

1. 申請／登入 [GitHub](https://github.com/)，建立新 Repository（例如 `stock-sensitivity-lab`）。
2. 解壓縮下載的 ZIP，將 `app.py`、`requirements.txt`、`README.md` 三個檔案放進 Repository 根目錄（GitHub 網頁的 **Add file → Upload files**）。注意 GitHub 不會自動替你解壓 ZIP。
3. 登入 [Streamlit Community Cloud](https://share.streamlit.io/) 並授權連接 GitHub。
4. 點 **Create app** / **Deploy an app**，選擇這個 Repository，main file 選 `app.py`，部署。
5. 開啟產生的網址，先測試 `2454`、基準日選最近完成收盤的交易日、回看 `3 個月`、預測期選 `1/3/5/10/20`，按 **開始回測**。

或者本機安裝 Python 3.11–3.13 後執行：

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## 目前已有

- 可選股票（會試上市 `.TW` 與上櫃 `.TWO`）、歷史截止基準日、回看 1 / 3 / 6 / 12 個月、預測 1 / 3 / 5 / 10 / 20 **個實際交易日**。
- KD、RSI、MACD 的固定、可審計示範訊號規則。
- t 日收盤產生訊號；t+1 日開盤作為進場參考；t+h 日收盤檢驗方向結果。僅評估歷史截止日已經成熟的訊號。
- 顯示成功率、成功數/樣本數、95% Wilson 區間、相同期間的無條件方向基準比例、平均方向報酬。
- 簡易當下訊號表與 CSV 下載。

## 要明確知道的限制

- 這是 **歷史訊號方向命中率**，不是保證未來成功的機率，也尚未構成可實際交易的完整績效回測。
- 每種指標的設定是暫時固定的；參數自訂、自創指標、條件排名儲存及指標失效警報放在下一階段。
- RSI 使用 Wilder 指數平滑，KD 使用 SMA 平滑而非所有看盤軟體採用的遞迴式方法；比較前要固定公式版本。
- 資料源 yfinance 為 Yahoo Finance 非官方取得方式，可能暫時失效；可改成 FinMind 台股 API。金融資料來源可能有速率、授權及時效限制。
- Yahoo 的調整價可能被後續股利修正，若需要嚴格逐日復原歷史當時的行情檔，應更換可提供 point-in-time 調整資料的來源。
- 尚未計入交易稅、手續費、滑價、不可成交限制、樣本重疊／短樣本偏誤；研究用結果不能直接等同交易收益。
- Streamlit Community Cloud 實際部署需要 GitHub 授權；執行環境可能休眠，記憶體快取不等於永久儲存。

## 第二階段規格

1. 把技術指標獨立成可註冊的函式，讓網頁可調 KD、RSI、MACD 參數與使用者自創公式。
2. 增加「歷史任一天」滾動回測頁，把當下的最佳指標排名和後續時間的排名作比較；不要求長期持續有效。
3. 可選成功定義：方向命中、漲幅門檻、扣費後淨報酬；另外分離買進與賣出訊號。
4. 對 1/3/5/10/20 交易日分別註明有多少已完成預測，以及校正重疊樣本。
5. 有需要時才保存**小量統計結果**（日期、股票、指標、參數、horizon、勝率、樣本數），而不是大量歷史行情。可以先存 SQLite、之後換 Supabase Postgres。

# 油洗洗 v0.2：有限預算的研究原型（2026-11-04）

本專案已定名為 **油洗洗**。原本的 `app.py` 日線研究功能仍然保留，另外增加：

- **近期加權成功率**：對已驗證的歷史訊號採半衰期權重 `w=0.5^(距今交易日/半衰期)`，並列「近期有效樣本數」；這只是歷史研究的穩定性觀察，不能稱作已校準的預測機率。
- **TXO 買方現金試算**：以每點新臺幣 50 元乘以權利金與口數，檢查目前現金上限、單筆限額與估計雙邊費用；只示範單純買進後平倉，完全不支援選擇權賣方風險。
- **獲利轉長期資產池**：模擬帳戶超過本月投入上限部分的轉出金額。沒有券商連線或自動轉帳功能。
- **交易日誌樣板** `journal_template.csv`：每筆模擬交易紀錄訊號、進出場、費稅、權利金與已實現損益，後續才能做策略歸因。範例為人工示範，不代表歷史價格。
- **測試** `python -m unittest test_risk.py`：確保單筆預算與資金轉出規則正常。

## 今晚最小可行步驟

1. 解壓縮並把 `app.py`、`risk.py`、`requirements.txt`、`README.md`、`test_risk.py`、`journal_template.csv` 六個檔案上傳到自己的 GitHub Repository 根目錄。
2. 用 [Streamlit Community Cloud](https://share.streamlit.io/) 連接該 Repo，入口檔為 `app.py`。
3. 在網頁輸入股票代號（先試 `2454`）、回看 3–12 個月、預測期 1/3/5/10/20 交易日；對照一般成功率和近期加權成功率。
4. 找到頁面下方的 **資金防火牆**，先模擬 NT$10,000、單筆 NT$1,500、TXO 權利金 20 點，確認在成本計入後是否可下單。
5. 先模擬、不下真單。接下來要建立盤中資料和各履約價選擇權權利金歷史，否則任何「指標看對方向」都不能推論「選擇權能賺錢」。

## 資金紀律草案（請自行確認是否適用）

- 每月只核准最多 NT$10,000 的交易資金，當月不得補錢追損，禁止借款、使用保證金或賣出選擇權。
- 先試一筆最多 NT$1,500（含預估費用）、持倉風險合計不得超過交易帳戶現金；若所有可買契約都超過單筆限額，當天就不交易，不用強行買便宜但沒有優勢的深價外契約。
- 資產池獲利出金：交易帳戶超過本月核准風險本金部分才轉到高股息 ETF 帳戶，不會把下一筆交易額度跟著獲利滾大。
- 當日或本月虧損超出事先核准門檻時停止模擬／交易並復盤。止損委託無法保證在指定價格成交，買方最大損失仍可能是已付全部權利金加成本。

## 須先解決的「當沖 vs 日線」差距

目前 RSI、KD、MACD 由**日收盤資料**產生，次一營業日開盤買入並在 1/3/5/10/20 交易日之後驗證方向，**不是當沖回測**。當沖必須取得可用時間戳記的分鐘/K線、當時可見的歷史資料、實際可成交 bid/ask、手續費/稅費、滑價，且買權/賣權對應的**歷史選擇權價格**、波動率與到期日。個股訊號也不能直接用來預測追蹤大盤的 TXO。請不要在尚未驗證上述資料前把原型結果當成選擇權買賣訊號。
