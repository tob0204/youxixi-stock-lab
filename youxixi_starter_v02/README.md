# 油洗洗 v0.8｜GitHub + Streamlit Community Cloud

> 正式名稱：**油洗洗｜台股隔日訊號回測**。本版只提供日 K 的收盤後研究，**不連券商、不同步下單、不使用選擇權**。本機完全不需要安裝 Python 或 Streamlit。

## 你可以直接操作的只有兩項判斷門檻

選擇股票後，左側留下：

1. **最低要求的歷史勝率（%）**：預設 **90%**，可直接修改，採「嚴格大於」條件。
2. **最低有效回測樣本數**：預設 **20 次**。這是**符合限價且結果已完成的樣本總數**，不是只統計成功次數。

原先讓使用者選擇的「是否啟用近期加權／近期最低有效樣本／近期加權半衰期」移除，改由系統內建 20 個交易日半衰期、最低近期有效樣本數 5 並顯示白話檢查結果：

- **最近表現是否還達標？**
- **證據量是否足夠？成功／失敗各幾筆？**
- **多空是否互相衝突？**

其他也不需選：**當下最新完整收盤日**、**預測下一個交易日（僅 1 天）**、**10 種指標**，以及 **2 週／1 個月／3 個月／6 個月／12 個月**五個訓練窗，皆由程式自動處理。

## 五個畫面

1. **明日交易結論**：目前收盤價、買／賣／觀望、明日開盤可接受限價（若有）、該條件下歷史成功率、推估次日收盤價與所採用技術指標／訓練期間。
2. **全台股買賣掃描**：分批掃描每批 40 檔。只列買入／賣出候選；其他股票不列入清單。**明確顯示已掃描/總數及失敗數**。公開行情不保證可快速一次完成所有股票；未掃描的不當成「觀望」。
3. **逐日前推與樣本證據**：在樣本數上移動滑鼠，顯示是哪一天訊號、哪一天驗證、成功或失敗；點選該指標與回測期間可看全部逐筆日期、價格、淨報酬並下載 CSV。過去一年每一交易日都以「前一日為資料截止」重新比較五期間，驗證隔日的實際收盤價，並統計開盤是否符合限價。
4. **十種指標公式**：MA、EMA、KD、MACD、布林通道、RSI、斐波那契、一目均衡表、標準差、ADX 的數學定義、觸發規則與對應 Python 程式碼。
5. **原始價格與計算數值**：OHLCV、所有指標中間值、每日觸發事件，並可 CSV 匯出。

## 特別重要：回測一年是什麼意思？

假設今天是 2026-11-04，則驗證 2026-11-04 當天的預測時，只能使用截至 **2026-11-03** 收盤前**已經完成**的歷史訊號及結果（例如 2025-11-03～2026-11-03 的 12 個月訓練窗）。接著再以 2026-11-02 為截止預測 11-03，以此類推至一年前的交易日。

- 「訊號日 T 收盤後」：有 KD 等技術訊號時，提出 **下一個交易日 T+1** 的研究候選。
- 「T+1 開盤價符合建議限價」：才假設有機會進場。買入時是開盤不高於限價、看跌研究時是開盤不低於限價。
- 「T+1 收盤」：用當日收盤價衡量假設的方向報酬，再扣示範成本（0.45 個百分點）。
- **一筆成功**＝符合開盤限價假設而且扣成本後的方向報酬為正。沒符合限價的交易不算成功也不算失敗。
- 「勝率」是**樣本內發生比例**，並非今日已校準的保證機率。過去一年逐日前推的累積成功率是獨立展示的驗證結果，不應與樣本內勝率混為一談。

本版建議「價格」不是預知明天開盤價；限價使用當時訓練窗的歷史隔日跳空幅度分位數，估計收盤價使用歷史隔日變動中位數。實際成交、停利停損先後仍需分鐘線與券商資料驗證。看跌研究不代表實際可放空。

## 直接更新 GitHub，不必在本機安裝任何程式

1. 在本機**下載 ZIP、解壓縮**（僅作為上傳檔案用途，不需執行安裝檔）。
2. 進入你既有的 GitHub Repository，將檔案上傳至**專案根目錄**，更新原本的同名檔案。若網頁上傳無法覆蓋，可按 `.` 進入 GitHub 網頁版程式編輯器，直接在雲端覆蓋、提交。
3. **保留原本部署**：Streamlit Community Cloud 的入口檔是 `app.py`，套件清單 `requirements.txt`，一般會在新 commit 後自動部署。
4. 在網站標題確認版本為 **v0.8**。不需要重新建立 Streamlit App。

## 發布前的真實限制

- 公開 yfinance 不保證在 Streamlit Cloud 可一次抓取全台股多年日 K；掃描採分批操作，超時、限流或官方上市櫃名單服務異常會顯示缺漏，不得默認為「全部股票已掃描」。
- 本版仍是**日 K 的開盤到收盤一日策略假設**，不是盤中分鐘線當沖執行回測；沒有模擬盤中停損、停利、掛單深度、實際滑價、日內觸價順序與放空限制。
- 使用自動調整過的 Yahoo 歷史日線，可能有**事後除權息調整偏差**；若用於實際下單，必須先用官方價格、逐日公司行動、交易規則確認。
- 五個訓練期間互相重疊、十指標同時選模，歷史最大勝率仍可能是過度擬合；逐日前推有助檢驗，但仍不能保證外推。
- 未提供保證盈利或自動投資服務。本系統不直接賣出選擇權，也無法將表內「賣出」當成合法放空指令。
